Pick one direction, or a mix (for example the Title card base plus katakana accents), and record it in docs/decisions.md. In the Full broadcast frames, hover the card to see the VHS hover, which turns into a static offset under reduced motion.

The toggles below change every frame at once: three dark palettes (all text pairs at 4.5:1 or better), the display face, and a fansub-style subtitle for the explanation line. The combination is kept in the URL, so a link brings back the same view.
